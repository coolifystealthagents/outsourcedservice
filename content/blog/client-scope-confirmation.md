# Confirm client scope before work starts

A bounded client scope confirmation guide for outsourced service teams.

## Why this control matters

The client scope confirmation record needs a source, owner, and close condition before work moves.

## What to check first

Compare the record with the approved scope and label missing fields instead of guessing.

## Handle the exceptions

Route each exception to the accountable owner with a dated next action.

## Review the evidence

Sample one routine item, one exception, and one corrected item each week.
